# Jev RAG benchmark explorer

This static Space is a no-key, no-backend view of the Jev RAG retrieval
benchmark. It compares BM25, agentic lexical search, hybrid retrieval, and
Jev reranking on the complete BEIR NFCorpus test split.

The numbers are project-run results, not an official MTEB submission. See the
[full benchmark report](https://github.com/aifabrice/jev-rag/blob/main/benchmarks/NFCORPUS_RESULTS.md)
and the [MTEB NFCorpus task](https://leaderboard.mteb.org/tasks/NFCorpus).
