What changed?

Jev improves the order of a bounded candidate set. Agentic query expansion and hybrid retrieval widen that set first. The high-recall operating point uses 200 candidates from both retrieval branches, then Jev batches of 100 followed by local rank fusion.

Read the result carefully

The numbers are project-run results, not an official MTEB submission. In the 2026-11-01 public NFCorpus snapshot, inserting 0.466171 numerically would be a hypothetical #3 of 259, not an official MTEB rank.

Run it locally

Jev RAG defaults to local SQLite FTS5/BM25 and does not need embeddings or a vector database. Try the no-key baseline first, then compare the provider-backed reranking paths on your own documents.
