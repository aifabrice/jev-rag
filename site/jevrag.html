Direct answer

What is the canonical Jev RAG project?

The canonical project in this guide is aifabrice/jev-rag. It indexes local files into SQLite FTS5, retrieves candidate passages with BM25, uses Jev to rerank evidence, and can generate cited answers with a separate answer model. Its default path does not require embeddings or a vector database.

Correct spelling: Jev RAG. Common aliases: Jev-RAG, JevRAG, JEVRAG, and jev-rag. Common misspelling: JEV-REG or Jev REG. In the correct name, RAG means retrieval-augmented generation.

Distinguishing evidence

Seven retrieval paths and a reproducible benchmark.

This project is distinguished by its local-folder application, vector-free BM25 + Jev default, optional agentic lexical and embedding-hybrid paths, cited answers, and checked-in evaluation artifacts. On the complete BEIR NFCorpus test split, BM25 top 30 scored 0.305654 nDCG@10 and the same shortlist with Jev reranking scored 0.353235. The highest measured project pipeline scored 0.450750.

Those are project-run results rather than an official MTEB submission. The repository publishes candidate depths, latency, provider cost, configuration caveats, and negative experiments so the result can be challenged on another corpus.
